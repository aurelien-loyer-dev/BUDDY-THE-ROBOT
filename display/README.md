# Écran de diffusion Buddy (Next.js)

Transcription en direct des échanges avec Buddy, aux couleurs de la charte Epitech (Anton / IBM Plex Sans / Space Mono, bleu `#013afb` + triptyque Tech/Together/Tomorrow).

- `npm run dev` avec `NEXT_PUBLIC_WS_HOST=<ip_buddy>` : dev local branché sur le robot.
- `npm run android` : export statique copié dans `../app/src/main/assets/web/`.

Voir le README racine (section « Écran de diffusion ») pour l'architecture.
